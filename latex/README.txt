Compile Tang_Chengfeng_HW2.tex with XeLaTeX (twice).
Keep all output_*.png figures in the same directory as the .tex file.

Example:
xelatex -interaction=nonstopmode -halt-on-error Tang_Chengfeng_HW2.tex
xelatex -interaction=nonstopmode -halt-on-error Tang_Chengfeng_HW2.tex

The source uses the standard Jupyter nbconvert LaTeX style and Latin Modern
fonts. A full TeX Live installation or Overleaf with XeLaTeX supplies the
required packages. Code and outputs remain beside their corresponding answers.
